The problem

Averages hide the damage.

Teams add skills, retries, reflection and bigger budgets, then check one number. But every upgrade rescues some runs and breaks others. A small net gain can hide thousands of regressions, and a skill that looks useless on average can be exploiting a shortcut underneath.

Built on research

Five ways agent interventions backfire.

From a matched study of skills, harnesses and budgets across nine benchmarks and four models.

Helps Hurts Baseline
Case 01

An evolved skill learned the benchmark’s shortcut

On a multiple-choice math benchmark, one recurring answer option is correct whenever it appears. Automatically built skills picked this up and told the agent to watch for it. Accuracy soared where the option appears, and fell everywhere else, as the rule got over-applied. Averaged over the whole benchmark, the effect can look like a modest gain or like nothing at all.

Case 02

A score-optimized skill broke a working system

On a reading-comprehension QA task, a strong model did well with no skill at all. A skill that had been optimized for score on another model overrode the expected answer format, and the same model collapsed. The capability was still there; the skill had rewritten the contract.

Case 03

A stronger harness faithfully executes the wrong policy

On a procedure-following workflow, a stronger execution harness took the agent from 33.9 to 88.6 when no skill was supplied. With a mismatched skill, the agent stayed stuck at the floor at every harness level. More execution support carried out the bad plan; it did not repair it.

Case 04

The same upgrade rescues thousands and breaks thousands

Across 85,392 matched runs, upgrading the harness rescued 3,886 runs that had failed, and broke 2,340 runs that had been correct. A benchmark average only shows the difference between the two.

3,886 rescued
2,340 broken
Case 05

Self-evolving skills learn procedures, not facts

On a factual-recall benchmark, switching models changed accuracy by about 61 points, while every self-evolved skill, harness and extra budget moved it by less than one point. A procedure cannot supply a missing fact. In follow-up experiments, writing the knowledge directly into the skill may recover it.
